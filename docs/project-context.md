# GenMod 当前项目上下文

GenMod 是 Vue 3 + Tauri 2 的本地 AI MOD 工作台。用户配置模型服务，通过项目中的会话修改 MOD 工作文件；经原生交付校验后产生版本，安装须经过预览及确认。工作文件、交付版本、项目记忆和跨项目长期记忆各有生命周期，不混作同一份数据。

## 当前能力与数据边界

- 项目、会话、聊天展示、工作文件、交付安装、项目记忆、长期记忆、反馈、游戏、Skills、设置与认证分别归属能力目录。工作台组合布局和导航。
- 页面读取会话只读投影并调用业务操作；传输 client 与运行时集合留在内部。切换页面不主动结束后台任务，结果按原项目/会话身份路由，同项目共享更新由应用协调入口交给所属能力。
- 原生持久任务记录是受理和终态依据。响应超时不等于未受理；待确认输入、附件、草稿与暂停队列保留已有恢复语义，不重复启动任务。
- 项目聚合读取仍返回完整 ModProject；资料、会话、交付、安装分别局部写入，保留 revision、事务与归档可写检查。首个会话在同一事务接管初始草稿，后续创建或无关写入不重复接管。
- 项目删除保留失败恢复；不因此删除游戏中的安装文件或跨项目长期记忆。启动恢复按既有顺序修复元数据和中断操作，不重放模型输入或安装文件。
- 两个版本入口复用操作，保留版本页删除后选最新、侧栏删除后清空选择的差异；取消导出不显示成功，部分删除失败后重读状态。
- 当前开放逃离鸭科夫和星露谷物语，其他清单项不因存在封面而开放制作。游戏目标目录提示由资源元数据提供，路径与交付安全检查仍由 Rust 负责。
- 本地和已下载官方 Skills 继续沿用选择、校验与快照规则。认证与云端更新暂保留，不以界面无入口判为废代码；凭据、模型配置与离线能力保持原边界。

## 运行时与维护入口

内置 Node/pi 版本来源为 runtime/runtime-lock.json；CLI、工具扩展和历史 helper 使用统一资源路径。声明一致性、资源存在检查、fixture 烟测和真实安装运行是不同证据。[运行时与构建说明](architecture/runtime-build.md)列明准备、构建、收集副作用及开发依赖恢复。
