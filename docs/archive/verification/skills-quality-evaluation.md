# Skills 质量评估

日期：2026-10-19。范围：mod-workflow、duckov-mod，版本 2.0.0。

## 结构与职责

| 资源 | 唯一维护职责 |
| --- | --- |
| common SKILL.md | 新建/续改/缺项/交付/反馈的选择入口 |
| common references/delivery.md | 命令与交付合同、上下文/反馈/知识/素材工具及证据边界 |
| Duckov SKILL.md | 游戏适用性、任务路由、工程入口及开发节奏 |
| api-sources.md | 直接来源、修订与可信度 |
| api-verification.md | 当前对象/签名/触发条件/副作用的查证方法 |
| dependencies.md | 引用职责、原始脚本参数与交付目录 |
| gameplay.md、ui-assets.md、harmony.md | 按任务读取的专题；未确认 API 保留缺口 |
| troubleshooting.md | 游戏专属排查、生命周期与玩家证据 |
| assets/template/* | 新工程输出模板；README 面向玩家 |
| scripts/* | 实际依赖检查、构建与显式资源整理 |
| references/inspection.json | 原生只读调查规则，不包含可执行指令 |

仅 Duckov 使用这些引擎资料，本期未创建空 Unity 公共技能。通用交付协议通过声明依赖的 mod-workflow 阅读，不创建越出单技能根目录的 Markdown 引用。
