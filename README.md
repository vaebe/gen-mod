# GenMod

用自然语言描述需求，让 AI 帮你制作和修改游戏 MOD。

GenMod 是一款 Windows 桌面工具，将 AI 对话、源码管理和 MOD 版本管理放在同一个工作台中。

## 下载

前往 [Releases](https://github.com/vaebe/gen-mod/releases) 下载 Windows x64 安装包（`.exe`）。无需另外安装 Node.js。

## 开始使用

1. **打开工作台**：无需注册或登录，也不依赖 GenMod 业务后端。
2. **配置模型**：在设置中添加模型服务，填写 API 地址、API Key 和模型信息，选择默认模型并保存。
3. **创建项目**：选择逃离鸭科夫或星露谷物语，描述想要的 MOD 功能，也可以附上图片。
4. **生成与调整**：在会话中查看进度，补充需求，让 AI 继续修改。
5. **安装或导出**：生成版本后，在版本管理中安装到游戏目录，或导出 ZIP。

## 主要功能

- **AI 制作 MOD**：通过对话生成、修改源码，查看执行过程和日志。
- **多会话协作**：同一项目可以同时开展多个会话，切换页面后任务继续运行。
- **文件预览**：查看项目源码、图片和文件变更。
- **版本管理**：查看历史产物，安装版本或导出 ZIP。
- **多模型支持**：支持 OpenAI、Anthropic、Google 及兼容接口。
- **本地游戏目录**：内置 20 款以中小体量独立游戏为主的清单与封面；目前逃离鸭科夫、星露谷物语开放制作，其余标记为待适配。
- **内置 Skills**：通用工作流、鸭科夫与星露谷能力随应用提供，首次使用无需从业务后端下载。
- **星露谷 MOD**：支持 Content Patcher 内容包与 SMAPI C# 两条制作路线，沿用版本登记、ZIP 导出与安装预览。

游戏图片统一存放在 `resources/games/images/<游戏ID>/`：`cover.jpg` 为横版封面，`icon.jpg` 为 32 × 32 的独立游戏图标。两者随应用打包，运行时不请求远程图片。清单格式、目录管理和图片来源见 [本地游戏资源说明](resources/games/README.md)。

## 使用须知

- 使用 AI 功能需要自行配置模型服务，费用以服务商为准。
- 制作 MOD 不要求安装游戏；编译所需的 SDK 或游戏参考程序集需另行准备。
- 星露谷运行需要玩家自行准备 SMAPI；内容包另需 Content Patcher。安装时选择游戏的 `Mods` 目录；C# 路线需要 .NET 6 SDK 及合法参考程序集，内容包无需 C# 编译。
- 安装前会展示目标文件和覆盖清单。确认安装后会直接覆盖文件，请提前备份。
- 安装完成后，仍需在游戏中启用 MOD 并确认实际效果与兼容性。
