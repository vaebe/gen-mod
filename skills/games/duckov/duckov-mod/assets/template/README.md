# ExampleMod

本模板由 AI 辅助编写，仅在屏幕角落显示 MOD 信息。未在游戏中验证效果。

## 适用范围与依赖

目标游戏版本与运行前置尚未核对，未声明已验证的兼容范围。交付包不包含游戏参考程序集。

## 安装与文件

交付文件包含当前 MOD DLL、info.ini、工具脚本绘制的 preview.png 和本说明。预览图是脚本生成的简洁标识，不包含游戏截图或第三方图片；用户可替换为自己有权使用的图片。

在工作台安装预览中选择游戏的 `Duckov_Data/Mods`，确认文件将放入独立的 `ExampleMod/` 子目录后安装，再在游戏中启用 ExampleMod。

## 用户验收

1. 在工作台确认当前交付版本安装成功，在游戏中启用该 MOD。
2. 观察屏幕角落是否显示 MOD 信息；若未显示，反馈启用状态、所在场景及相关截图或日志。

当前仅包含信息展示功能。编译、版本登记和安装状态以工作台当前版本记录为准，游戏内显示效果尚待用户验证。
